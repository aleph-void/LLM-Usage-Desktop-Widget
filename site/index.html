// Features

Every Limit, One Glance Away

No more opening a terminal to type /usage halfway through a task. The widget keeps the numbers next to your clock and tells you how long until each window resets.

Where Your Status Icons Live

A compact Claude 99%  Codex 13% readout in the Linux top bar, the macOS menu bar, or drawn right on the Windows taskbar, in the next empty gap, never over your buttons.

Every Window, Every Reset

Click for the full list: the 5-hour session, weekly windows and model-scoped limits, each with its percentage, a bar and the exact time until it resets.

Color at a Glance

Bars and icons turn amber at 70% and red at 90%, or follow the severity the provider reports. If a refresh fails, the last numbers stay up, marked stale.

Credits When the Plan Runs Out

Once a plan hits 100% and usage credits remain (Claude's extra usage or a Codex credit balance), the readout switches to what's left, like Claude 75% left.

Cutoff Quotas

Pick Stop Claude at 90% and the widget stops running claude CLI processes when the plan reaches it, then clears itself. Credit cutoffs cap extra spend the same way.

Zero Setup, Read-Only

Log in to claude and codex once and you're done. Credentials are only read, never modified, and the widget never refreshes tokens, so it can't log your CLI out.

Bedrock, Vertex & Azure

Running the CLIs on a cloud instead of a subscription? See spend against your budget, month-to-date cost and today's tokens from your existing AWS, Google Cloud or Azure login.

Settings That Follow You

On macOS and Windows, settings and cutoffs sync through iCloud Drive and OneDrive, even between a Mac with only iCloud and a PC with only OneDrive.

Floating Widget & Logo Mode

No tray? Run an always-on-top floating window instead. Want the numbers out of sight? Collapse to logo shows just the Aleph Void ℵ₀ mark until you click.

// Architecture

How It Works

The widget asks each provider the same question the official CLIs ask for their own /usage and /status screens, using the login you already have.

1

Reads Your Existing Logins

Claude Code's credentials from the macOS Keychain or ~/.claude, and the Codex CLI's from ~/.codex/auth.json. Cloud sections use your AWS, gcloud or az login.

  • Read, never written
  • No API keys to paste
2

Asks Only the Issuer

Each token goes only to the provider that issued it, over HTTPS, with redirects rejected and response sizes bounded. Nothing passes through an Aleph Void server.

  • No middleman, no telemetry
  • Owner-only settings files
3

Shows It Where You Look

Refreshes every 3 minutes (or every minute, if you like), then updates the readout, the colored icon and the menu. One copy runs at a time and starts with your session.

  • Refresh now, any time
  • Daily update check

// FAQ

Frequently Asked Questions

Is it really free?

Yes. LLM Usage Widget is open source under the MIT license, with no paid tier, account or license key. If it saves you a surprise lockout, you can sponsor Aleph Void on GitHub.

Do I need an API key?

No. The widget reads the login that Claude Code (claude) and the Codex CLI (codex) already store on your machine. Log in to each once with your subscription and it works. An API-key Codex login has no plan limits to show; use codex login with ChatGPT.

Is it safe to let it read my credentials?

Credentials are only read, never modified, and each token is sent only to the provider that issued it, over HTTPS with redirects rejected. The widget never refreshes tokens itself, because rotating a refresh token would log your CLI out. The code is open for you to check.

It says my login expired. What now?

Claude Code and Codex refresh their own tokens while you use them. If you haven't used one for a while, its access token can expire. Open that CLI once and the widget picks up the new token on its next refresh.

How does a cutoff stop the CLI?

On the first refresh that finds a provider at or over its cutoff, the widget stops every running process of that provider's CLI (claude or codex), leaves a note in the menu and turns the cutoff off so you can start again. The Claude and Codex desktop apps are never stopped. Usage is checked on each refresh, so a busy session can go slightly past the cutoff.

Which Linux desktops work?

Any panel with AppIndicator / StatusNotifierItem support. Ubuntu's GNOME works out of the box; on other GNOME setups enable the "AppIndicator and KStatusNotifierItem Support" extension. KDE, XFCE, Cinnamon and others work too, though some panels show only the icon. For desktops without a tray, run the floating window with --widget.

Why does Windows sometimes hide the numbers on the taskbar?

Windows has no API for text on the taskbar, so the widget uses a small window that follows it. After Start, Search or the Widgets board, Windows 11 can leave the taskbar in a layer no ordinary program can draw over, until the shell resets it. The tray icon and its tooltip still show the numbers meanwhile.

Will it break when a provider changes its API?

It might. The widget uses the same internal endpoints the official CLIs use for their /usage and /status screens, which are undocumented. If a provider shows an error after an update, a new release usually follows quickly, and the widget tells you when one is out.

Does it collect any data?

No analytics or telemetry. Apart from the providers you use, it only asks GitHub once a day whether a newer release exists. See the Privacy Policy.

Is this an official Anthropic or OpenAI app?

No. LLM Usage Widget is an independent project by Aleph Void LLC and is not affiliated with or endorsed by Anthropic, OpenAI, Amazon, Google or Microsoft.
