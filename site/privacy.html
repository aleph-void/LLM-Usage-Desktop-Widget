Your Tokens Go Only
Where They Came From

LLM Usage Widget has no analytics, no telemetry and no account. It talks to the providers you already use, with the logins you already have, and to GitHub once a day to check for updates. Nothing goes to Aleph Void.

Last updated: November 11, 2026

// Data Handling

What Leaves Your Computer

Usage requests to Anthropic and OpenAI

To read your plan usage, the widget sends the access token that Claude Code or the Codex CLI stored on your computer to the provider that issued it, and to no one else:

  • Claude: api.anthropic.com
  • Codex: chatgpt.com

Requests use HTTPS only and refuse redirects. Each provider handles them under its own privacy policy, as it does for the CLI itself.

Cloud providers (only if you use them)

The Bedrock, Vertex AI and Azure sections turn on only when your CLIs are set up to use that cloud, or when you enable them in config.json. They query that cloud's own billing and monitoring APIs with your existing credentials:

  • AWS: Budgets, Cost Explorer, CloudWatch, STS
  • Google Cloud: Cloud Monitoring, BigQuery (your billing export), OAuth token refresh
  • Azure: Azure Resource Manager, Cost Management, Azure Monitor

Update checks (GitHub)

Once a day the widget asks GitHub's public API (api.github.com) for the latest release of this project. The request carries no information about you or your usage; GitHub sees your IP address, as with any request. The answer is cached locally.

To turn the check off, add "update_check": false to config.json.

Settings sync (your own cloud drive)

On macOS and Windows, settings and cutoffs are written to an llm-usage-widget folder in your iCloud Drive or OneDrive, if either is signed in. Those services sync the folder under your own account; the widget does not upload anything itself.

To stop syncing on a computer, add "sync": false to its local config.json.

What we don't collect

No analytics, crash reporting or usage tracking. The widget never sends your credentials, usage numbers, account IDs, prompts or files to Aleph Void or any third party. Credentials are only read, never modified or copied elsewhere.

What's stored locally

  • config.json: your settings and cutoffs.
  • cloud-cache.json: cached cloud spend, token counts and the latest-release answer.

They live in ~/.config/llm-usage-widget, ~/Library/Application Support/llm-usage-widget or %APPDATA%\llm-usage-widget, with owner-only permissions on Linux and macOS.

This website

This site is hosted on GitHub Pages and loads fonts from Google Fonts. The download section asks GitHub's public API for the latest release so its buttons can link straight to the files. All of these receive standard request data such as your IP address. The site sets no cookies and runs no analytics.

Contact

Questions about this policy: support@alephvoid.com. Because the widget is open source, you can also read exactly what it sends in its source code. If this policy changes, the date above will change with it.
