How to Get Help

All support runs through the LLM-Usage-Desktop-Widget issue tracker on GitHub. You'll need a free GitHub account to file an issue.

Report a Bug

Wrong numbers, an error in the menu, or the widget not appearing? Tell us your OS and desktop, the widget version and what the menu shows.

File a bug report →

Request a Feature

Another provider, a different panel, a new kind of cutoff? Describe the use case. Pull requests are welcome too: a provider is one fetch_<name>() plus tests.

Suggest a feature →

Ask a Question

Not sure whether it's a bug or a setup issue? Open an issue anyway and label it as a question. The answer will help the next person too.

Ask a question →

Never post tokens or credential files in an issue. Issues are public. Redact .credentials.json, auth.json, account IDs and cloud keys from anything you paste. For something private, email support@alephvoid.com.
// Checklist

Before You File an Issue

A few quick checks that solve most problems.

1

Update

Install the latest release. Providers change their endpoints, and fixes ship fast.

2

Use the CLI Once

"Login expired"? Run claude or codex once so it refreshes its own token.

3

Try --once

Run usage_widget.py --once to print usage in the terminal, errors included.

4

Search Issues

Someone may have hit it already. Add details to an existing issue rather than opening a duplicate.

// Troubleshooting

Common Fixes

Linux: the icon doesn't appear

The widget needs a panel with AppIndicator support. On GNOME outside Ubuntu, install and enable AppIndicator and KStatusNotifierItem Support.

On Ubuntu with GNOME 50, the AppIndicators extension can come up half-broken at login, which also hides other apps' icons. install.sh reloads it once for you; to do it by hand:

gnome-extensions disable ubuntu-appindicators@ubuntu.com && gnome-extensions enable ubuntu-appindicators@ubuntu.com

No tray at all? Run the floating window: usage_widget.py --widget.

macOS: Keychain prompt

On first run, macOS asks whether the widget may read Claude Code-credentials from your Keychain. Choose Always Allow so it doesn't ask again.

macOS may also ask once for access to iCloud Drive or OneDrive, used for settings sync. Logs go to ~/Library/Logs/llm-usage-widget.log (script install).

To uninstall, run Uninstall LLM Usage Widget.pkg from the disk image.

Windows: numbers missing from the taskbar

The tray icon may be tucked into the overflow (^) menu; drag it onto the taskbar to keep it visible.

After Start, Search or the Widgets board, Windows 11 sometimes leaves the taskbar in a layer no ordinary program can draw over. The numbers come back when the shell resets it (signing out, or restarting Explorer). The tray icon and tooltip keep showing them meanwhile.

Make sure Show usage on the taskbar is ticked in the menu. If the taskbar is completely full, the readout waits until there's room.

Bedrock, Vertex & Azure errors

If a permission is missing, only that row shows an error. Common needs:

  • AWS: ce:GetCostAndUsage, cloudwatch:GetMetricData, and for budgets budgets:ViewBudget. Expired SSO? Run aws sso login.
  • Google Cloud: Monitoring Viewer, plus BigQuery Job User and read access to your billing export for spend.
  • Azure: Reader and Monitoring Reader on the resources, Cost Management Reader on the subscription.

Billing data is cached for hours and can lag by a day; Refresh now doesn't bypass the cache.

// Bug Reports

What to Include

A good bug report has

Your OS and version, and on Linux your desktop environment and panel · the widget version (in the menu or usage_widget.py --version) · how you installed it (package or script) · which providers you use (Claude, Codex, Bedrock, Vertex, Azure) and your plan · what the menu says, or the output of --once, with account IDs redacted · and a screenshot if it's a display problem.
